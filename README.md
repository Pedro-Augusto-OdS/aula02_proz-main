AULA 02 - PROGRAMACAO FRONT-END - PROZ
MINI-SITE EM HTML INSPIRADO NA WEB 1.0

ARQUIVOS
01_base_para_alunos.html: ponto de partida editavel para os estudantes.
02_exemplo_completo_professor.html: exemplo resolvido para o docente mostrar apos a atividade.

COMO USAR
1. Crie uma pasta chamada meu-primeiro-site.
2. Copie 01_base_para_alunos.html para a pasta e renomeie para index.html.
3. Abra index.html no VS Code ou Bloco de Notas.
4. Personalize titulos, paragrafos e lista; adicione tres links externos.
5. Salve e abra index.html com Chrome, Firefox ou Edge.
6. Volte ao editor para corrigir ou atualizar o texto. Salve e pressione F5 no navegador.

REQUISITOS DA ATIVIDADE
- 1 titulo principal com <h1> e pelo menos 2 subtitulos <h2>.
- 2 paragrafos autorais com <p>.
- 1 lista <ul> com pelo menos 3 itens <li>.
- 3 links externos funcionais com <a href="...">.
- Nao usar CSS ou JavaScript nesta primeira atividade.
- Arquivo final salvo como index.html.

OBSERVACAO: o arquivo HTML pode ser aberto sem conexao. Os links externos,
no entanto, precisam de internet para abrir os sites de destino.
